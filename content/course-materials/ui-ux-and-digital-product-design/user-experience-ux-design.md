# User Experience (UX) Design

_UI/UX and Digital Product Design · Faculty of Technology · Level 100L_

## Overview

UX Design examines the overall experience people have when using a product or service. Students learn user needs analysis, journey mapping, information architecture, usability principles, and experience evaluation. Projects investigate user problems and develop design solutions, helping learners reduce confusion, improve task completion, and create products that better match user expectations.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up user experience (ux) design.
- Describe user needs analysis and how it is used.
- Describe journey mapping and how it is used.
- Describe information architecture and how it is used.
- Describe usability principles and how it is used.
- Describe experience evaluation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

UI/UX and Digital Product Design focuses on creating digital products that are visually clear, accessible, and easy to use. Students learn user research, interface design, prototyping, usability evaluation, interaction principles, and design systems to improve how people interact with software.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about user experience (ux) design. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
