# Usability Testing

_UI/UX and Digital Product Design · Faculty of Technology · Level 100L_

## Overview

Usability Testing teaches students how to evaluate whether people can use a product to complete important tasks. Topics include test objectives, task design, participant selection, observation, issue severity, and findings reports. Practical exercises test prototypes or sample applications, helping learners identify confusion, measure task success, and recommend improvements based on evidence.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up usability testing.
- Describe test objectives and how it is used.
- Describe task design and how it is used.
- Describe participant selection and how it is used.
- Describe observation and how it is used.
- Describe issue severity and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

UI/UX and Digital Product Design focuses on creating digital products that are visually clear, accessible, and easy to use. Students learn user research, interface design, prototyping, usability evaluation, interaction principles, and design systems to improve how people interact with software.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about usability testing. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
