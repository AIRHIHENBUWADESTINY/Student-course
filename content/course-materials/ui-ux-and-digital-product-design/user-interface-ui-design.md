# User Interface (UI) Design

_UI/UX and Digital Product Design · Faculty of Technology · Level 100L_

## Overview

UI Design teaches students how to design the visual elements of digital products, including buttons, menus, forms, layouts, and navigation. Topics include typography, spacing, colour, visual hierarchy, consistency, and responsive layouts. Practical assignments create interface mockups and reusable components, helping learners communicate information clearly and support effective user interaction.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up user interface (ui) design.
- Describe buttons and how it is used.
- Describe menus and how it is used.
- Describe forms and how it is used.
- Describe layouts and how it is used.
- Describe navigation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

UI/UX and Digital Product Design focuses on creating digital products that are visually clear, accessible, and easy to use. Students learn user research, interface design, prototyping, usability evaluation, interaction principles, and design systems to improve how people interact with software.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about user interface (ui) design. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
