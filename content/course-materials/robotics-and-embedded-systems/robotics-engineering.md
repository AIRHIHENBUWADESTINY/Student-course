# Robotics Engineering

_Robotics and Embedded Systems · Faculty of Technology · Level 100L_

## Overview

Robotics Engineering introduces the design, programming, and operation of robots that perform physical tasks. Students explore mechanical structures, sensors, actuators, control systems, navigation, and robot programming. Practical projects may use simulated or educational robots, helping learners integrate hardware and software while considering precision, safety, reliability, and task requirements.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up robotics engineering.
- Describe mechanical structures and how it is used.
- Describe sensors and how it is used.
- Describe actuators and how it is used.
- Describe control systems and how it is used.
- Describe navigation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Robotics and Embedded Systems combines computing, electronics, sensing, and control to create devices that interact with the physical world. Students learn microcontrollers, embedded software, automation, sensors, and intelligent control for applications in industry, healthcare, transport, and consumer technology.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about robotics engineering. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
