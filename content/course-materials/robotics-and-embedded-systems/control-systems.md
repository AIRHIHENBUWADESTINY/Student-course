# Control Systems

_Robotics and Embedded Systems · Faculty of Technology · Level 100L_

## Overview

Control Systems examines how systems are regulated to achieve desired behaviour. Students study feedback, open-loop and closed-loop control, system response, stability, and introductory mathematical models. Practical exercises simulate or build simple control applications, helping learners understand how measurements guide corrective actions in machines, industrial processes, and automated devices.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up control systems.
- Describe feedback and how it is used.
- Describe open-loop and how it is used.
- Describe closed-loop control and how it is used.
- Describe system response and how it is used.
- Describe stability and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Robotics and Embedded Systems combines computing, electronics, sensing, and control to create devices that interact with the physical world. Students learn microcontrollers, embedded software, automation, sensors, and intelligent control for applications in industry, healthcare, transport, and consumer technology.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about control systems. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
