# Internet of Things (IoT)

_Robotics and Embedded Systems · Faculty of Technology · Level 100L_

## Overview

Internet of Things introduces connected devices that collect and exchange data over networks. Students explore sensors, embedded devices, connectivity, messaging protocols, cloud integration, and device management. Practical projects build a simple connected monitoring system, while addressing authentication, privacy, reliability, power consumption, and the security risks associated with internet-connected devices.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up internet of things (iot).
- Describe sensors and how it is used.
- Describe embedded devices and how it is used.
- Describe connectivity and how it is used.
- Describe messaging protocols and how it is used.
- Describe cloud integration and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Robotics and Embedded Systems combines computing, electronics, sensing, and control to create devices that interact with the physical world. Students learn microcontrollers, embedded software, automation, sensors, and intelligent control for applications in industry, healthcare, transport, and consumer technology.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about internet of things (iot). Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
