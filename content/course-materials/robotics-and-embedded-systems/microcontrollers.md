# Microcontrollers

_Robotics and Embedded Systems · Faculty of Technology · Level 100L_

## Overview

Microcontrollers examines compact integrated circuits used to control electronic devices. Students learn processor basics, memory, digital and analogue inputs, timers, communication interfaces, and peripheral control. Practical laboratory work connects microcontrollers to sensors and output devices, teaching learners to build simple control systems and troubleshoot interactions between code and hardware.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up microcontrollers.
- Describe processor basics and how it is used.
- Describe memory and how it is used.
- Describe digital and how it is used.
- Describe analogue inputs and how it is used.
- Describe timers and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Robotics and Embedded Systems combines computing, electronics, sensing, and control to create devices that interact with the physical world. Students learn microcontrollers, embedded software, automation, sensors, and intelligent control for applications in industry, healthcare, transport, and consumer technology.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about microcontrollers. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
