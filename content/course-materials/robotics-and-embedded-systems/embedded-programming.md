# Embedded Programming

_Robotics and Embedded Systems · Faculty of Technology · Level 100L_

## Overview

Embedded Programming teaches students to develop software for dedicated computing devices inside larger products. Topics include resource constraints, input/output operations, interrupts, timing, memory management, and hardware interfaces. Practical exercises program microcontrollers to control simple devices, helping learners understand the relationship between software, electronic components, and real-time system behaviour.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up embedded programming.
- Describe resource constraints and how it is used.
- Describe input/output operations and how it is used.
- Describe interrupts and how it is used.
- Describe timing and how it is used.
- Describe memory management and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Robotics and Embedded Systems combines computing, electronics, sensing, and control to create devices that interact with the physical world. Students learn microcontrollers, embedded software, automation, sensors, and intelligent control for applications in industry, healthcare, transport, and consumer technology.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about embedded programming. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
