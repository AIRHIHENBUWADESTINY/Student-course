# Wireless Networking

_Computer Networking · Faculty of Technology · Level 100L_

## Overview

Wireless Networking is part of the Computer Networking area. Wireless Networking focuses on communication technologies that connect devices without physical network cables. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up wireless networking.
- Describe wi-fi standards and how it is used.
- Describe access points and how it is used.
- Describe radio frequency concepts and how it is used.
- Describe wireless authentication and how it is used.
- Describe coverage and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Networking studies how computers, servers, and other devices communicate and share resources. Students learn network architecture, protocols, addressing, routing, wireless communication, troubleshooting, and network protection, developing skills needed to build and maintain dependable digital communication systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about wireless networking. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
