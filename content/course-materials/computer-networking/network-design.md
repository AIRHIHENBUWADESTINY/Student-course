# Network Design

_Computer Networking · Faculty of Technology · Level 100L_

## Overview

Network Design teaches students how to plan network infrastructure around organizational requirements. Topics include topology, addressing schemes, segmentation, redundancy, capacity planning, security, and equipment selection. Students create network diagrams and design solutions for sample homes, campuses, or businesses, balancing reliability, performance, growth, and budget constraints while documenting their design decisions.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up network design.
- Describe topology and how it is used.
- Describe addressing schemes and how it is used.
- Describe segmentation and how it is used.
- Describe redundancy and how it is used.
- Describe capacity planning and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Networking studies how computers, servers, and other devices communicate and share resources. Students learn network architecture, protocols, addressing, routing, wireless communication, troubleshooting, and network protection, developing skills needed to build and maintain dependable digital communication systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about network design. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
