# Telecommunications

_Computer Networking · Faculty of Technology · Level 100L_

## Overview

Telecommunications is part of the Computer Networking area. Telecommunications examines the technologies used to transmit voice, video, and data over communication systems. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up telecommunications.
- Describe technologies used to transmit voice and how it is used.
- Describe video and how it is used.
- Describe data over communication systems and how it is used.
- Describe transmission media and how it is used.
- Describe cellular networks and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Networking studies how computers, servers, and other devices communicate and share resources. Students learn network architecture, protocols, addressing, routing, wireless communication, troubleshooting, and network protection, developing skills needed to build and maintain dependable digital communication systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about telecommunications. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
