# 2D and 3D Animation

_Digital Media and Creative Technology · Faculty of Technology · Level 100L_

## Overview

2D and 3D Animation introduces techniques for creating movement in digital media. Students explore keyframes, timing, character movement, rigging, modelling, lighting, and rendering. Practical assignments produce short animated sequences using suitable software, helping learners understand storytelling, motion principles, production workflows, and the technical considerations involved in creating polished animations.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up 2d and 3d animation.
- Describe keyframes and how it is used.
- Describe timing and how it is used.
- Describe character movement and how it is used.
- Describe rigging and how it is used.
- Describe modelling and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Digital Media and Creative Technology combines artistic communication with digital tools used to create visual, animated, interactive, and audio content. Students learn design principles, media production, modelling, editing, and immersive technologies for education, entertainment, marketing, and digital communication.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about 2d and 3d animation. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
