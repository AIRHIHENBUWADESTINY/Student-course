# Graphic Design

_Digital Media and Creative Technology · Faculty of Technology · Level 100L_

## Overview

Graphic Design teaches students how to communicate ideas through visual compositions. Topics include typography, colour theory, layout, branding, image editing, visual hierarchy, and design principles. Practical projects produce posters, logos, social media graphics, and other communication materials, helping learners develop creative problem-solving skills and create clear, audience-appropriate visual messages.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up graphic design.
- Describe typography and how it is used.
- Describe colour theory and how it is used.
- Describe layout and how it is used.
- Describe branding and how it is used.
- Describe image editing and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Digital Media and Creative Technology combines artistic communication with digital tools used to create visual, animated, interactive, and audio content. Students learn design principles, media production, modelling, editing, and immersive technologies for education, entertainment, marketing, and digital communication.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about graphic design. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
