# Virtual Reality (VR)

_Digital Media and Creative Technology · Faculty of Technology · Level 100L_

## Overview

Virtual Reality introduces computer-generated environments designed to provide immersive experiences. Students explore spatial interaction, scene design, tracking, navigation, interface placement, and performance requirements. Practical projects create simple virtual environments or demonstrations, while considering accessibility, comfort, privacy, hardware limitations, and appropriate applications in education, training, simulation, and entertainment.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up virtual reality (vr).
- Describe spatial interaction and how it is used.
- Describe scene design and how it is used.
- Describe tracking and how it is used.
- Describe navigation and how it is used.
- Describe interface placement and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Digital Media and Creative Technology combines artistic communication with digital tools used to create visual, animated, interactive, and audio content. Students learn design principles, media production, modelling, editing, and immersive technologies for education, entertainment, marketing, and digital communication.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about virtual reality (vr). Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
