# Data Engineering

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Data Engineering focuses on building systems that collect, transform, store, and deliver data for analysis. Students explore data pipelines, extraction and transformation, batch processing, streaming, data quality, and workflow scheduling. Projects demonstrate how to combine data from different sources into reliable datasets, while emphasizing scalability, documentation, monitoring, and maintainability.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data engineering.
- Describe data pipelines and how it is used.
- Describe extraction and how it is used.
- Describe transformation and how it is used.
- Describe batch processing and how it is used.
- Describe streaming and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data engineering. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
