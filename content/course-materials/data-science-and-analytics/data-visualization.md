# Data Visualization

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Data Visualization teaches students how to communicate information through charts, graphs, maps, and interactive dashboards. Learners explore visual encoding, chart selection, colour accessibility, layout, and storytelling with data. Practical assignments transform datasets into clear visual explanations, helping audiences recognize patterns, compare values, and understand findings without misleading representations.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data visualization.
- Describe visual encoding and how it is used.
- Describe chart selection and how it is used.
- Describe colour accessibility and how it is used.
- Describe layout and how it is used.
- Describe storytelling with data and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data visualization. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
