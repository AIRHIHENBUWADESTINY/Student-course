# Data Analysis

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Data Analysis teaches students to transform raw data into meaningful information. Learners study data cleaning, filtering, grouping, descriptive statistics, exploratory analysis, and interpretation. Practical exercises use spreadsheets, SQL, or programming tools to answer questions from datasets, identify trends, and communicate findings clearly while recognizing missing information, bias, and data-quality problems.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data analysis.
- Describe data cleaning and how it is used.
- Describe filtering and how it is used.
- Describe grouping and how it is used.
- Describe descriptive statistics and how it is used.
- Describe exploratory analysis and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data analysis. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
