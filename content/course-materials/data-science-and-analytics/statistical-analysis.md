# Statistical Analysis

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Statistical Analysis introduces mathematical methods for understanding data and drawing evidence-based conclusions. Students study probability, distributions, sampling, estimation, hypothesis testing, correlation, and regression. Practical exercises analyse real or simulated datasets and interpret results carefully, helping learners distinguish meaningful relationships from coincidence and understand uncertainty when making decisions.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up statistical analysis.
- Describe probability and how it is used.
- Describe distributions and how it is used.
- Describe sampling and how it is used.
- Describe estimation and how it is used.
- Describe hypothesis testing and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about statistical analysis. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
