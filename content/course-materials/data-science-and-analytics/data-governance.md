# Data Governance

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Data Governance examines the policies and responsibilities required to manage data properly throughout its lifecycle. Students study data ownership, quality standards, classification, access permissions, privacy, metadata, and retention. Practical exercises create governance rules for sample datasets, helping learners improve consistency, accountability, security, and appropriate use of organizational information.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data governance.
- Describe policies and how it is used.
- Describe data ownership and how it is used.
- Describe quality standards and how it is used.
- Describe classification and how it is used.
- Describe access permissions and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data governance. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
