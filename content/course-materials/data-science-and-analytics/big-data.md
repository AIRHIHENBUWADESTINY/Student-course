# Big Data

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Big Data introduces technologies and methods for processing datasets too large, fast, or complex for conventional approaches. Students explore distributed storage, parallel processing, data pipelines, batch workloads, and streaming systems. Practical activities examine how distributed platforms process large datasets, while considering data quality, scalability, privacy, reliability, and processing costs.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up big data.
- Describe distributed storage and how it is used.
- Describe parallel processing and how it is used.
- Describe data pipelines and how it is used.
- Describe batch workloads and how it is used.
- Describe streaming systems and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about big data. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
