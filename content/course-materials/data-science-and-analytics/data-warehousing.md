# Data Warehousing

_Data Science and Analytics · Faculty of Technology · Level 100L_

## Overview

Data Warehousing is part of the Data Science and Analytics area. Data Warehousing teaches students how to organize integrated data for reporting and analysis. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data warehousing.
- Describe warehouse architecture and how it is used.
- Describe fact and how it is used.
- Describe dimension tables and how it is used.
- Describe star schemas and how it is used.
- Describe data transformation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Data Science and Analytics focuses on collecting, preparing, analysing, and interpreting data to support decisions. Students learn statistical reasoning, programming, data visualization, data management, and analytical methods for discovering patterns, evaluating performance, and communicating useful findings to different audiences.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data warehousing. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
