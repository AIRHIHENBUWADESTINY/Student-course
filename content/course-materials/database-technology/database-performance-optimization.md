# Database Performance Optimization

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Database Performance Optimization teaches students how to improve the speed and efficiency of database operations. Topics include query analysis, indexing, execution plans, schema design, caching, and workload monitoring. Practical exercises identify slow queries and compare optimization strategies, helping learners reduce unnecessary processing and improve response times without compromising data correctness or security.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up database performance optimization.
- Describe query analysis and how it is used.
- Describe indexing and how it is used.
- Describe execution plans and how it is used.
- Describe schema design and how it is used.
- Describe caching and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about database performance optimization. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
