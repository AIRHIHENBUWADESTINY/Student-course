# Relational Databases

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Relational Databases is part of the Database Technology area. Relational Databases teaches students how to organize information into related tables. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up relational databases.
- Describe tables and how it is used.
- Describe rows and how it is used.
- Describe columns and how it is used.
- Describe primary keys and how it is used.
- Describe foreign keys and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about relational databases. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
