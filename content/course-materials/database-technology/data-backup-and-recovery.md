# Data Backup and Recovery

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Data Backup and Recovery is part of the Database Technology area. Data Backup and Recovery examines techniques for protecting information against accidental deletion, hardware failure, and service disruptions. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up data backup and recovery.
- Describe hardware failure and how it is used.
- Describe service disruptions and how it is used.
- Describe full and how it is used.
- Describe incremental backups and how it is used.
- Describe recovery objectives and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about data backup and recovery. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
