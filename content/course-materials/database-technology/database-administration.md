# Database Administration

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Database Administration teaches students how to maintain database systems and ensure they operate reliably. Topics include user permissions, configuration, monitoring, backup scheduling, updates, performance checks, and troubleshooting. Practical activities administer a sample database and review its health, helping learners protect information, maintain availability, and document routine operational procedures.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up database administration.
- Describe user permissions and how it is used.
- Describe configuration and how it is used.
- Describe monitoring and how it is used.
- Describe backup scheduling and how it is used.
- Describe updates and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about database administration. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
