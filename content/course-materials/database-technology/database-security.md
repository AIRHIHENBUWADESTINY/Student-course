# Database Security

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Database Security teaches students how to protect stored information against unauthorized access, disclosure, and alteration. Topics include authentication, permissions, encryption, secure queries, auditing, backups, and data privacy. Practical exercises configure appropriate access controls and review common weaknesses, helping learners apply least-privilege principles and protect sensitive information throughout its lifecycle.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up database security.
- Describe authentication and how it is used.
- Describe permissions and how it is used.
- Describe encryption and how it is used.
- Describe secure queries and how it is used.
- Describe auditing and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about database security. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
