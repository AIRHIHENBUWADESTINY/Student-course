# Distributed Databases

_Database Technology · Faculty of Technology · Level 100L_

## Overview

Distributed Databases explores systems that store and process data across multiple servers or locations. Students study replication, partitioning, consistency, availability, fault tolerance, and distributed transactions. Practical examples illustrate how distributed systems handle growth and failures, while helping learners understand trade-offs involved in keeping information accessible and consistent across multiple locations.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up distributed databases.
- Describe systems that store and how it is used.
- Describe replication and how it is used.
- Describe partitioning and how it is used.
- Describe consistency and how it is used.
- Describe availability and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Database Technology focuses on designing, storing, organizing, retrieving, and protecting digital information. Students learn data modelling, querying, database administration, performance optimization, recovery, and security to support applications that depend on accurate and accessible information.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about distributed databases. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
