# Operating System Support

_Information Technology (IT) Support · Faculty of Technology · Level 100L_

## Overview

Operating System Support teaches students how to install, configure, maintain, and troubleshoot computer operating systems. Topics include user accounts, updates, drivers, file permissions, system settings, software installation, and recovery tools. Practical tasks resolve common system problems and improve performance, helping learners support users across appropriate desktop operating environments.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up operating system support.
- Describe user accounts and how it is used.
- Describe updates and how it is used.
- Describe drivers and how it is used.
- Describe file permissions and how it is used.
- Describe system settings and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

IT Support focuses on helping people and organizations maintain functional, secure, and reliable computer systems. Students develop troubleshooting, hardware, software, user support, administration, and service-management skills needed to resolve technical issues and keep everyday technology operating effectively.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about operating system support. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
