# Technical Troubleshooting

_Information Technology (IT) Support · Faculty of Technology · Level 100L_

## Overview

Technical Troubleshooting teaches systematic methods for identifying and resolving computer and software problems. Students learn symptom analysis, hypothesis testing, diagnostic tools, root-cause analysis, documentation, and solution verification. Practical scenarios involve hardware, operating systems, connectivity, and application errors, helping learners solve problems methodically rather than relying on guesses or unverified fixes.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up technical troubleshooting.
- Describe symptom analysis and how it is used.
- Describe hypothesis testing and how it is used.
- Describe diagnostic tools and how it is used.
- Describe root-cause analysis and how it is used.
- Describe documentation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

IT Support focuses on helping people and organizations maintain functional, secure, and reliable computer systems. Students develop troubleshooting, hardware, software, user support, administration, and service-management skills needed to resolve technical issues and keep everyday technology operating effectively.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about technical troubleshooting. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
