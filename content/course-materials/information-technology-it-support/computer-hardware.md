# Computer Hardware

_Information Technology (IT) Support · Faculty of Technology · Level 100L_

## Overview

Computer Hardware introduces the physical components of computer systems and how they work together. Students study processors, memory, storage devices, motherboards, power supplies, peripherals, and basic assembly. Practical exercises identify components and diagnose common hardware faults, while emphasizing safe handling, compatibility, maintenance, and responsible equipment management.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up computer hardware.
- Describe processors and how it is used.
- Describe memory and how it is used.
- Describe storage devices and how it is used.
- Describe motherboards and how it is used.
- Describe power supplies and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

IT Support focuses on helping people and organizations maintain functional, secure, and reliable computer systems. Students develop troubleshooting, hardware, software, user support, administration, and service-management skills needed to resolve technical issues and keep everyday technology operating effectively.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about computer hardware. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
