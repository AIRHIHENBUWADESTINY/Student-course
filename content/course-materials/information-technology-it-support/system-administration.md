# System Administration

_Information Technology (IT) Support · Faculty of Technology · Level 100L_

## Overview

System Administration is part of the Information Technology (IT) Support area. System Administration teaches students how to manage and maintain computer systems and servers. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up system administration.
- Describe user accounts and how it is used.
- Describe permissions and how it is used.
- Describe updates and how it is used.
- Describe monitoring and how it is used.
- Describe storage and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Information Technology (IT) Support prepares students to maintain, troubleshoot, and support computer systems, networks, and users. Students learn hardware and software support, system administration, service management, asset management, and backup practices that keep organizational technology running reliably.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about system administration. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
