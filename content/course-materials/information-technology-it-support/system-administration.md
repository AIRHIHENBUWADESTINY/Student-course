# System Administration

_Information Technology (IT) Support · Faculty of Technology · Level 100L_

## Overview

System Administration teaches students how to manage computer systems, users, services, and operational settings. Topics include account management, permissions, updates, system monitoring, storage, networking, and routine maintenance. Practical exercises configure sample systems and troubleshoot common issues, helping learners maintain availability, security, and consistency in organizational computing environments.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up system administration.
- Describe account management and how it is used.
- Describe permissions and how it is used.
- Describe updates and how it is used.
- Describe system monitoring and how it is used.
- Describe storage and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

IT Support focuses on helping people and organizations maintain functional, secure, and reliable computer systems. Students develop troubleshooting, hardware, software, user support, administration, and service-management skills needed to resolve technical issues and keep everyday technology operating effectively.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about system administration. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
