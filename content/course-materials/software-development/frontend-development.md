# Frontend Development

_Software Development · Faculty of Technology · Level 100L_

## Overview

Frontend Development is part of the Software Development area. Frontend Development teaches students how to build the visible parts of websites and web applications. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up frontend development.
- Describe html for structure and how it is used.
- Describe css for styling and how it is used.
- Describe javascript for interactivity and how it is used.
- Describe responsive design and how it is used.
- Describe accessibility and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about frontend development. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
