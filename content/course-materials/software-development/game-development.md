# Game Development

_Software Development · Faculty of Technology · Level 100L_

## Overview

Game Development introduces the programming, design, and production techniques used to create digital games. Students explore game mechanics, player interaction, physics, animation, sound, level design, and game engines. Practical assignments encourage learners to build playable prototypes, test gameplay, optimize performance, and understand the collaboration required in game production.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up game development.
- Describe game mechanics and how it is used.
- Describe player interaction and how it is used.
- Describe physics and how it is used.
- Describe animation and how it is used.
- Describe sound and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about game development. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
