# Backend Development

_Software Development · Faculty of Technology · Level 100L_

## Overview

Backend Development introduces the server-side technologies that power applications. Students learn how to process requests, implement business logic, authenticate users, manage databases, and protect sensitive information. Topics include server frameworks, application architecture, error handling, validation, and deployment. Practical exercises help students build reliable services that support frontend applications.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up backend development.
- Describe to process requests and how it is used.
- Describe implement business logic and how it is used.
- Describe authenticate users and how it is used.
- Describe manage databases and how it is used.
- Describe protect sensitive information and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about backend development. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
