# Desktop Application Development

_Software Development · Faculty of Technology · Level 100L_

## Overview

Desktop Application Development teaches students to create software that runs on personal computers. Topics include graphical user interfaces, file management, local databases, operating-system integration, application security, and packaging. Students learn to design applications for Windows, macOS, or Linux, while developing practical skills in debugging, usability, performance, and software maintenance.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up desktop application development.
- Describe graphical user interfaces and how it is used.
- Describe file management and how it is used.
- Describe local databases and how it is used.
- Describe operating-system integration and how it is used.
- Describe application security and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about desktop application development. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
