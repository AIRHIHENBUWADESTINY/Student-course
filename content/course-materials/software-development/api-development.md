# API Development

_Software Development · Faculty of Technology · Level 100L_

## Overview

API Development teaches students how to create interfaces that allow software systems to communicate. Topics include REST APIs, HTTP methods, request and response formats, authentication, authorization, validation, documentation, and error handling. Students build services that exchange data securely between applications and learn how to test, version, maintain, and integrate APIs.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up api development.
- Describe REST APIs and how it is used.
- Describe HTTP methods and how it is used.
- Describe request and how it is used.
- Describe response formats and how it is used.
- Describe authentication and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about api development. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
