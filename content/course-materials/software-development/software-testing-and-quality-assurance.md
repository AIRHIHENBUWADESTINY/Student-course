# Software Testing and Quality Assurance

_Software Development · Faculty of Technology · Level 100L_

## Overview

Software Testing and Quality Assurance teaches students how to verify that applications behave as expected. Learners explore test planning, manual testing, automated testing, unit tests, integration tests, regression testing, and defect reporting. Practical exercises develop skills in identifying bugs, evaluating requirements, improving reliability, and maintaining software quality throughout development.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up software testing and quality assurance.
- Describe test planning and how it is used.
- Describe manual testing and how it is used.
- Describe automated testing and how it is used.
- Describe unit tests and how it is used.
- Describe integration tests and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Software Development focuses on designing, building, testing, deploying, and maintaining software applications. Students learn programming, application architecture, problem-solving, user interface development, and software quality practices used to create reliable solutions for individuals and organizations.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about software testing and quality assurance. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
