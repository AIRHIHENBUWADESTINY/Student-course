# Generative AI

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Generative AI introduces systems that create text, images, audio, code, and other forms of content. Students explore language models, image generation, prompts, retrieval-supported generation, output evaluation, and practical applications. The course also examines hallucinations, intellectual property, privacy, bias, and responsible use, emphasizing human review when generated content affects important decisions.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up generative ai.
- Describe language models and how it is used.
- Describe image generation and how it is used.
- Describe prompts and how it is used.
- Describe retrieval-supported generation and how it is used.
- Describe output evaluation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about generative ai. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
