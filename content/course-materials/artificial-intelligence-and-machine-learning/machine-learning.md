# Machine Learning

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Machine Learning teaches students how computer systems learn patterns from data to make predictions or decisions. Topics include supervised and unsupervised learning, classification, regression, clustering, feature engineering, and model evaluation. Practical exercises train and test introductory models, helping learners understand data splitting, overfitting, accuracy measures, and responsible interpretation of predictions.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up machine learning.
- Describe supervised and how it is used.
- Describe unsupervised learning and how it is used.
- Describe classification and how it is used.
- Describe regression and how it is used.
- Describe clustering and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about machine learning. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
