# Deep Learning

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Deep Learning is part of the Artificial Intelligence and Machine Learning area. Deep Learning introduces neural networks with multiple processing layers for learning complex patterns. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up deep learning.
- Describe network structure and how it is used.
- Describe activation functions and how it is used.
- Describe loss functions and how it is used.
- Describe optimization and how it is used.
- Describe training data and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about deep learning. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
