# Speech Recognition

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Speech Recognition teaches students how computers convert spoken language into machine-readable text or commands. Topics include audio signals, feature extraction, acoustic modelling, speech-to-text systems, and evaluation. Practical exercises examine recorded speech or existing recognition tools, while considering accents, background noise, accessibility, language coverage, and privacy in voice-enabled applications.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up speech recognition.
- Describe audio signals and how it is used.
- Describe feature extraction and how it is used.
- Describe acoustic modelling and how it is used.
- Describe speech-to-text systems and how it is used.
- Describe evaluation and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about speech recognition. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
