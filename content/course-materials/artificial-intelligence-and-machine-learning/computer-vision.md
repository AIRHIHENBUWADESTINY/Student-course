# Computer Vision

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Computer Vision teaches students how computers analyse images and video to identify useful information. Topics include image processing, feature extraction, image classification, object detection, and evaluation methods. Practical activities use sample images to build or test vision models, while discussing image quality, privacy, fairness, and the limitations of automated visual recognition.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up computer vision.
- Describe image processing and how it is used.
- Describe feature extraction and how it is used.
- Describe image classification and how it is used.
- Describe object detection and how it is used.
- Describe evaluation methods and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about computer vision. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
