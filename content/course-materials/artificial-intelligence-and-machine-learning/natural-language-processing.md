# Natural Language Processing

_Artificial Intelligence and Machine Learning · Faculty of Technology · Level 100L_

## Overview

Natural Language Processing focuses on enabling computers to process and interpret human language. Students explore text preprocessing, tokenization, language classification, sentiment analysis, information extraction, and language modelling. Practical projects analyse text datasets or build simple language tools, while considering ambiguity, language diversity, privacy, and the risk of biased or inaccurate outputs.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up natural language processing.
- Describe text preprocessing and how it is used.
- Describe tokenization and how it is used.
- Describe language classification and how it is used.
- Describe sentiment analysis and how it is used.
- Describe information extraction and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Artificial Intelligence and Machine Learning explore techniques that enable computers to identify patterns, make predictions, understand information, and generate outputs. Students learn data preparation, model development, evaluation, responsible use, and the limitations of intelligent systems in practical applications.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about natural language processing. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
