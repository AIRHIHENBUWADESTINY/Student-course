# Containerization

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Containerization introduces the packaging of applications and their dependencies into portable execution environments. Students learn container images, registries, container runtimes, networking, volumes, and configuration. Practical exercises package an application into a container and run it consistently across environments, while covering image maintenance, resource management, and basic container security.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up containerization.
- Describe container images and how it is used.
- Describe registries and how it is used.
- Describe container runtimes and how it is used.
- Describe networking and how it is used.
- Describe volumes and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about containerization. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
