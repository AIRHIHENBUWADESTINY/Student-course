# Infrastructure as Code

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Infrastructure as Code teaches students to manage computing infrastructure through version-controlled configuration files instead of manual setup. Topics include declarative definitions, reusable modules, state management, environment consistency, and change review. Practical exercises provision sample infrastructure and demonstrate how automation improves repeatability, auditability, collaboration, and recovery from configuration errors.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up infrastructure as code.
- Describe declarative definitions and how it is used.
- Describe reusable modules and how it is used.
- Describe state management and how it is used.
- Describe environment consistency and how it is used.
- Describe change review and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about infrastructure as code. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
