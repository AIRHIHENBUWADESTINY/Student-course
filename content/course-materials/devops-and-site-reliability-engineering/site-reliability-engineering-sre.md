# Site Reliability Engineering (SRE)

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Site Reliability Engineering applies software engineering practices to operating reliable services. Students study service-level indicators, service-level objectives, error budgets, incident management, capacity planning, and post-incident reviews. Practical exercises assess service reliability and investigate simulated outages, helping learners balance system stability with development speed while using measurable objectives to guide improvements.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up site reliability engineering (sre).
- Describe service-level indicators and how it is used.
- Describe service-level objectives and how it is used.
- Describe error budgets and how it is used.
- Describe incident management and how it is used.
- Describe capacity planning and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about site reliability engineering (sre). Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
