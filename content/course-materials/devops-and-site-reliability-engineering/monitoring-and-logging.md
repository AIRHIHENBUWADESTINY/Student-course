# Monitoring and Logging

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Monitoring and Logging is part of the DevOps and Site Reliability Engineering area. Monitoring and Logging teaches students how to understand application and infrastructure behaviour through collected metrics, logs, and traces. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up monitoring and logging.
- Describe dashboards and how it is used.
- Describe alert rules and how it is used.
- Describe log aggregation and how it is used.
- Describe service health and how it is used.
- Describe troubleshooting and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about monitoring and logging. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
