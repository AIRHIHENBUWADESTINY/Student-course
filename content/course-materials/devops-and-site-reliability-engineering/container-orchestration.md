# Container Orchestration

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Container Orchestration teaches students how to manage containerized applications across multiple machines. Topics include deployments, services, scheduling, scaling, health checks, configuration, and workload recovery. Students explore orchestration platforms such as Kubernetes and practise deploying a sample application, helping them understand how automated systems maintain application availability and manage changing workloads.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up container orchestration.
- Describe deployments and how it is used.
- Describe services and how it is used.
- Describe scheduling and how it is used.
- Describe scaling and how it is used.
- Describe health checks and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about container orchestration. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
