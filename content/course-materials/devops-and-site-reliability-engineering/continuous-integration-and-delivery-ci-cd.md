# Continuous Integration and Delivery (CI/CD)

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

This course teaches students how to automate software building, testing, and deployment. Learners explore source control, automated test pipelines, build processes, deployment stages, and release management. Practical projects connect a code repository to a pipeline that validates changes before deployment, improving consistency, reducing manual work, and helping teams deliver software more frequently.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up continuous integration and delivery (ci/cd).
- Describe source control and how it is used.
- Describe automated test pipelines and how it is used.
- Describe build processes and how it is used.
- Describe deployment stages and how it is used.
- Describe release management and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about continuous integration and delivery (ci/cd). Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
