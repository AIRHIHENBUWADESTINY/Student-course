# Automation and Scripting

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Automation and Scripting is part of the DevOps and Site Reliability Engineering area. Automation and Scripting introduces the use of programming and command-line tools to automate repetitive technical tasks. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up automation and scripting.
- Describe variables and how it is used.
- Describe conditions and how it is used.
- Describe loops and how it is used.
- Describe functions and how it is used.
- Describe file operations and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about automation and scripting. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
