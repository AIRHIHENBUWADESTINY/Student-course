# Configuration Management

_DevOps and Site Reliability Engineering · Faculty of Technology · Level 100L_

## Overview

Configuration Management focuses on keeping systems consistently configured across development, testing, and production environments. Students learn configuration files, automated provisioning, reusable playbooks, version control, and configuration drift detection. Practical exercises automate common administration tasks and standardize system settings, reducing manual errors and improving reliability, security, and operational efficiency.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up configuration management.
- Describe configuration files and how it is used.
- Describe automated provisioning and how it is used.
- Describe reusable playbooks and how it is used.
- Describe version control and how it is used.
- Describe configuration drift detection and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

DevOps and Site Reliability Engineering combine software development and IT operations to deliver applications reliably and efficiently. Students learn automation, continuous delivery, infrastructure management, monitoring, incident response, and collaborative practices that help teams deploy changes safely and maintain dependable services.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about configuration management. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
