# Computer Architecture

_Computer Science · Faculty of Technology · Level 100L_

## Overview

Computer Architecture explains how computer hardware components work together to execute programs. Students study processors, registers, memory hierarchies, instruction sets, input/output systems, and data representation. The course examines how hardware design influences performance and energy consumption. Practical exercises may include assembly-language examples, processor simulations, and performance comparisons.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up computer architecture.
- Describe processors and how it is used.
- Describe registers and how it is used.
- Describe memory hierarchies and how it is used.
- Describe instruction sets and how it is used.
- Describe input/output systems and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Science studies the fundamental principles behind computing systems, algorithms, programming, and information processing. Students learn how computers solve problems, represent data, execute instructions, and support intelligent applications, while developing analytical thinking and computational problem-solving skills.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about computer architecture. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
