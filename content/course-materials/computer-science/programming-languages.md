# Programming Languages

_Computer Science · Faculty of Technology · Level 100L_

## Overview

Programming Languages is part of the Computer Science area. Programming Languages introduces the principles and characteristics of languages used to develop software. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up programming languages.
- Describe syntax and how it is used.
- Describe data types and how it is used.
- Describe variables and how it is used.
- Describe control structures and how it is used.
- Describe functions and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Science studies the fundamental principles behind computing systems, algorithms, programming, and information processing. Students learn how computers solve problems, represent data, execute instructions, and support intelligent applications, while developing analytical thinking and computational problem-solving skills.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about programming languages. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
