# Human-Computer Interaction

_Computer Science · Faculty of Technology · Level 100L_

## Overview

Human-Computer Interaction is part of the Computer Science area. Human-Computer Interaction studies how people interact with computers and digital systems. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up human-computer interaction.
- Describe how people interact with computers and how it is used.
- Describe digital systems and how it is used.
- Describe usability and how it is used.
- Describe interface design and how it is used.
- Describe human behaviour and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Science studies the fundamental principles behind computing systems, algorithms, programming, and information processing. Students learn how computers solve problems, represent data, execute instructions, and support intelligent applications, while developing analytical thinking and computational problem-solving skills.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about human-computer interaction. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
