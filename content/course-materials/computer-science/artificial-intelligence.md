# Artificial Intelligence

_Computer Science · Faculty of Technology · Level 100L_

## Overview

Artificial Intelligence is part of the Computer Science area. This course introduces computer systems designed to perform tasks associated with intelligent behaviour. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up artificial intelligence.
- Describe search algorithms and how it is used.
- Describe knowledge representation and how it is used.
- Describe reasoning and how it is used.
- Describe planning and how it is used.
- Describe decision-making and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Science studies the fundamental principles behind computing systems, algorithms, programming, and information processing. Students learn how computers solve problems, represent data, execute instructions, and support intelligent applications, while developing analytical thinking and computational problem-solving skills.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about artificial intelligence. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
