# Algorithms and Data Structures

_Computer Science · Faculty of Technology · Level 100L_

## Overview

Algorithms and Data Structures is part of the Computer Science area. This course explores methods for organizing data and solving computational problems efficiently. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up algorithms and data structures.
- Describe methods for organizing data and how it is used.
- Describe solving computational problems efficiently and how it is used.
- Describe arrays and how it is used.
- Describe linked lists and how it is used.
- Describe stacks and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Computer Science studies the fundamental principles behind computing systems, algorithms, programming, and information processing. Students learn how computers solve problems, represent data, execute instructions, and support intelligent applications, while developing analytical thinking and computational problem-solving skills.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about algorithms and data structures. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
