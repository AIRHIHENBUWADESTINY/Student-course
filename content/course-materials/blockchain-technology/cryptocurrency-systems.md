# Cryptocurrency Systems

_Blockchain Technology · Faculty of Technology · Level 100L_

## Overview

Cryptocurrency Systems is part of the Blockchain Technology area. Cryptocurrency Systems introduces the technical principles behind digital currencies that use cryptographic and distributed network mechanisms. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cryptocurrency systems.
- Describe wallets and how it is used.
- Describe transactions and how it is used.
- Describe public and how it is used.
- Describe private keys and how it is used.
- Describe consensus and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Blockchain Technology explores distributed systems that maintain shared records across participating computers. Students learn blockchain architecture, transaction validation, consensus, smart contracts, and decentralized applications, while examining security, transparency, scalability, privacy, and practical limitations of blockchain-based solutions.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cryptocurrency systems. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
