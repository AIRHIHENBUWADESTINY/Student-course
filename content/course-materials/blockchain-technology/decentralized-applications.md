# Decentralized Applications

_Blockchain Technology · Faculty of Technology · Level 100L_

## Overview

Decentralized Applications is part of the Blockchain Technology area. Decentralized Applications examines software that interacts with blockchain networks and smart contracts. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up decentralized applications.
- Describe smart contracts and how it is used.
- Describe user interfaces and how it is used.
- Describe wallet connections and how it is used.
- Describe transaction signing and how it is used.
- Describe contract integration and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Blockchain Technology explores distributed systems that maintain shared records across participating computers. Students learn blockchain architecture, transaction validation, consensus, smart contracts, and decentralized applications, while examining security, transparency, scalability, privacy, and practical limitations of blockchain-based solutions.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about decentralized applications. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
