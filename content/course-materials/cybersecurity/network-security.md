# Network Security

_Cybersecurity · Faculty of Technology · Level 100L_

## Overview

Network Security teaches students how to protect communication networks from attacks and unauthorized access. Topics include firewalls, secure network configurations, intrusion detection, encryption, access controls, and traffic monitoring. Practical exercises focus on identifying weaknesses, understanding common network threats, and applying defensive measures to improve the security and reliability of network infrastructure.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up network security.
- Describe firewalls and how it is used.
- Describe secure network configurations and how it is used.
- Describe intrusion detection and how it is used.
- Describe encryption and how it is used.
- Describe access controls and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cybersecurity focuses on protecting computers, networks, applications, and information from unauthorized access, misuse, and digital threats. Students learn security principles, risk assessment, defensive technologies, incident response, and ethical practices for maintaining confidentiality, integrity, and availability of digital systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about network security. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
