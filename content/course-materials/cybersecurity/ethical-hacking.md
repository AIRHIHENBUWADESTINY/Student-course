# Ethical Hacking

_Cybersecurity · Faculty of Technology · Level 100L_

## Overview

Ethical Hacking introduces authorized security assessment techniques used to identify system vulnerabilities. Students study reconnaissance concepts, vulnerability assessment, security testing methodologies, and responsible reporting. Practical work must take place in authorized laboratories or controlled environments. The course emphasizes permission, legal boundaries, documentation, and remediation rather than unauthorized access to real systems.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up ethical hacking.
- Describe reconnaissance concepts and how it is used.
- Describe vulnerability assessment and how it is used.
- Describe security testing methodologies and how it is used.
- Describe responsible reporting and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cybersecurity focuses on protecting computers, networks, applications, and information from unauthorized access, misuse, and digital threats. Students learn security principles, risk assessment, defensive technologies, incident response, and ethical practices for maintaining confidentiality, integrity, and availability of digital systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about ethical hacking. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
