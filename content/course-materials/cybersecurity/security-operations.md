# Security Operations

_Cybersecurity · Faculty of Technology · Level 100L_

## Overview

Security Operations is part of the Cybersecurity area. Security Operations focuses on monitoring systems and responding to cybersecurity incidents. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up security operations.
- Describe about security information and how it is used.
- Describe event management and how it is used.
- Describe log analysis and how it is used.
- Describe alert investigation and how it is used.
- Describe incident classification and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cybersecurity focuses on protecting computers, networks, applications, and information from unauthorized access, misuse, and digital threats. Students learn security principles, risk assessment, defensive technologies, incident response, and ethical practices for maintaining confidentiality, integrity, and availability of digital systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about security operations. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
