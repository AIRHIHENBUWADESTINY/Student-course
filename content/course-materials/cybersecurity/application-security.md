# Application Security

_Cybersecurity · Faculty of Technology · Level 100L_

## Overview

Application Security focuses on identifying and preventing vulnerabilities in software. Students learn secure coding, input validation, authentication, authorization, session management, dependency security, and security testing. They examine common application weaknesses and practise defensive development techniques. The course encourages integrating security checks throughout the software development lifecycle rather than treating security as a final step.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up application security.
- Describe secure coding and how it is used.
- Describe input validation and how it is used.
- Describe authentication and how it is used.
- Describe authorization and how it is used.
- Describe session management and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cybersecurity focuses on protecting computers, networks, applications, and information from unauthorized access, misuse, and digital threats. Students learn security principles, risk assessment, defensive technologies, incident response, and ethical practices for maintaining confidentiality, integrity, and availability of digital systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about application security. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
