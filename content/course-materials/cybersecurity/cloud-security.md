# Cloud Security

_Cybersecurity · Faculty of Technology · Level 100L_

## Overview

Cloud Security examines methods for protecting applications, data, and infrastructure hosted by cloud providers. Students learn identity management, encryption, access policies, secure configurations, logging, and incident response. The course also introduces shared responsibility models and cloud security monitoring, helping learners understand how organizations reduce risks when using cloud-based computing resources.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud security.
- Describe methods for protecting applications and how it is used.
- Describe data and how it is used.
- Describe infrastructure hosted by cloud providers and how it is used.
- Describe identity management and how it is used.
- Describe encryption and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cybersecurity focuses on protecting computers, networks, applications, and information from unauthorized access, misuse, and digital threats. Students learn security principles, risk assessment, defensive technologies, incident response, and ethical practices for maintaining confidentiality, integrity, and availability of digital systems.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud security. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
