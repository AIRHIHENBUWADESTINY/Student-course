# Serverless Computing

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Serverless Computing introduces application development using managed cloud services that reduce the need to administer servers directly. Students explore event-driven functions, managed databases, triggers, permissions, and service integration. Practical projects demonstrate how applications respond to events and scale with demand, while covering execution limits, observability, reliability, and cost considerations.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up serverless computing.
- Describe event-driven functions and how it is used.
- Describe managed databases and how it is used.
- Describe triggers and how it is used.
- Describe permissions and how it is used.
- Describe service integration and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about serverless computing. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
