# Cloud Architecture

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Architecture teaches students how to design reliable, secure, and scalable systems using cloud services. Topics include architectural patterns, high availability, fault tolerance, load balancing, disaster recovery, and service selection. Students develop simple architecture diagrams and evaluate design trade-offs, learning how to match cloud resources to application needs and operational requirements.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud architecture.
- Describe architectural patterns and how it is used.
- Describe high availability and how it is used.
- Describe fault tolerance and how it is used.
- Describe load balancing and how it is used.
- Describe disaster recovery and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud architecture. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
