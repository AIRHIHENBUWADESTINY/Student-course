# Cloud Infrastructure

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Infrastructure introduces the computing resources used to run applications in cloud environments. Students learn about virtual machines, compute instances, storage, networking, availability, and resource provisioning. Practical exercises involve creating and configuring basic cloud resources, monitoring their usage, and understanding how organizations scale infrastructure to meet changing application requirements.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud infrastructure.
- Describe virtual machines and how it is used.
- Describe compute instances and how it is used.
- Describe storage and how it is used.
- Describe networking and how it is used.
- Describe availability and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud infrastructure. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
