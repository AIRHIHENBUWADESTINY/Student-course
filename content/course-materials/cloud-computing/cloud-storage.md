# Cloud Storage

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Storage is part of the Cloud Computing area. Cloud Storage teaches students how to store, retrieve, protect, and manage data using cloud services. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud storage.
- Describe object storage and how it is used.
- Describe block storage and how it is used.
- Describe file storage and how it is used.
- Describe backups and how it is used.
- Describe replication and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud storage. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
