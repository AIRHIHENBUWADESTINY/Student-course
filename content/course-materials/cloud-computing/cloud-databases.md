# Cloud Databases

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Databases examines database services hosted and managed through cloud platforms. Students learn about relational and non-relational databases, provisioning, backups, replication, scaling, access control, and performance monitoring. Practical exercises involve creating a database, connecting an application, and applying basic security measures while comparing managed services with self-managed database deployments.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud databases.
- Describe database services hosted and how it is used.
- Describe managed through cloud platforms and how it is used.
- Describe relational and how it is used.
- Describe non-relational databases and how it is used.
- Describe provisioning and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud databases. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
