# Cloud Security

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Security focuses on protecting cloud-hosted resources, workloads, and information. Students study identity permissions, encryption, security groups, network controls, secrets management, monitoring, and incident response. The course explores secure configuration and shared responsibility between cloud providers and customers, helping learners identify common risks and apply appropriate safeguards to cloud environments.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud security.
- Describe identity permissions and how it is used.
- Describe encryption and how it is used.
- Describe security groups and how it is used.
- Describe network controls and how it is used.
- Describe secrets management and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud security. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
