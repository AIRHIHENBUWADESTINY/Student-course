# Cloud Networking

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Networking examines how networks are designed and configured within cloud platforms. Students study virtual networks, subnets, routing, gateways, firewalls, private connectivity, and network access controls. Practical activities involve connecting cloud resources securely and troubleshooting connectivity issues, helping learners understand how cloud networking supports communication between applications, users, and external systems.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud networking.
- Describe networks are designed and how it is used.
- Describe configured within cloud platforms and how it is used.
- Describe virtual networks and how it is used.
- Describe subnets and how it is used.
- Describe routing and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud networking. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
