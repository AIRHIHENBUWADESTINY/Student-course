# Cloud Cost Management

_Cloud Computing · Faculty of Technology · Level 100L_

## Overview

Cloud Cost Management is part of the Cloud Computing area. Cloud Cost Management teaches students how to monitor and control spending on cloud resources. This self-study guide takes you from the core vocabulary through to a small practical project so you can learn at your own pace.

## Learning Objectives

By the end of this course you should be able to:

- Explain the main ideas that make up cloud cost management.
- Describe pricing models and how it is used.
- Describe budgets and how it is used.
- Describe cost allocation tags and how it is used.
- Describe usage reports and how it is used.
- Describe resource optimization and how it is used.
- Apply the concepts to a small, realistic task.
- Recognise common mistakes and know how to avoid them.

## Introduction

Cloud Computing teaches students how computing resources such as servers, databases, storage, and networking can be delivered over the internet. Students explore cloud service models, infrastructure management, deployment, security, scalability, and cost control using modern cloud platforms and architectures.

In this subject, the goal is not just to memorise facts but to build a reliable way of thinking about cloud cost management. Work through each lesson in order, try the examples, and answer the review questions before moving on. If a term is new, write a one-line definition in your own words — that habit alone will make the material stick.
